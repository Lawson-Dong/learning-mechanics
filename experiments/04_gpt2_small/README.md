# GPT-2 Small

This experiment trains GPT-2 small on WikiText-2 and analyzes parameter-trajectory dynamics.

## Notebook

- `GPT_2_small.ipynb`

The notebook uses Hugging Face datasets/models and generates `.npz` trajectory/analysis outputs.

## Dependencies

```bash
pip install -r ../../requirements/gpt2.txt
```

Training requires internet access and a suitable PyTorch environment. Generated archives and model artifacts are not committed to Git.
